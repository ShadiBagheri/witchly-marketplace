# UX/UI Review & Recommendations

## 1. Introduction

As part of this technical assessment, I conducted a UX/UI review of the original Witchly website to identify usability issues, visual inconsistencies, and potential areas for improvement.

The review focused on evaluating the existing interface, navigation experience, visual hierarchy, and overall usability of the marketplace.

The following sections outline the identified issues, their impact on users, and practical recommendations for improvement.

## 2. Identified Issues & Recommendations

### 2.1. Homepage Visual Clutter

**Priority:** High

**Issue:**

The homepage contains numerous visual elements and sections, making the initial experience feel overwhelming. New visitors may find it difficult to understand where to start or which content deserves their attention.

**Impact:**

- Increases cognitive load for new visitors.
- Makes it harder to identify important content.
- Can negatively affect the overall browsing experience.

**Recommendation:**

Simplify the homepage by reducing unnecessary visual elements, prioritizing important content, and establishing a clearer content hierarchy.

### 2.2. Insufficient Section Spacing

**Priority:** Medium

**Issue:**

The vertical spacing between sections is insufficient, causing adjacent sections to feel crowded and visually connected.

**Impact:**

- Reduces content readability.
- Makes it harder to distinguish between different sections.
- Creates a less balanced visual experience.

**Recommendation:**

Introduce a consistent spacing system with appropriate vertical gaps between sections to improve visual separation, readability, and overall page composition.

### 2.3. Oversized Section Headings

**Priority:** Low

**Issue:**

Section headings are disproportionately large and compete visually with other content, disrupting the overall visual hierarchy.

**Impact:**

- Creates an unbalanced typography hierarchy.
- Draws excessive attention to section titles.
- Reduces visual consistency across the page.

**Recommendation:**

Refine the typography scale and use more balanced heading sizes to create a consistent visual hierarchy across different sections.

### 2.4. Hero Section Communication

**Priority:** High

**Issue:**

The homepage hero section relies heavily on large visual boxes and decorative elements, while the platform's purpose and core value proposition could be communicated more directly.

**Impact:**

- Makes it harder for new visitors to immediately understand the platform.
- Reduces clarity around the services offered.
- Delays users' understanding of what they can do on the marketplace.

**Recommendation:**

Use a concise and meaningful headline supported by a short description that clearly explains what Witchly offers and how users can benefit from the platform. Include a relevant call-to-action to guide visitors toward the next step.

### 2.5. Duplicate Search Interfaces

**Priority:** Medium

**Issue:**

Some pages display a search box in the shared header as well as an additional search box within the page content, resulting in potentially unnecessary repetition of the same functionality.

**Impact:**

- Creates visual redundancy.
- May cause confusion about the purpose of each search interface.
- Reduces consistency in page layouts.

**Recommendation:**

Define clearer layout patterns for different page types and use shared components consistently. Avoid duplicating search functionality unless the additional search interface serves a distinct purpose.

### 2.6. Excessive Animations

**Priority:** Medium

**Issue:**

The website uses animations extensively across different sections, including animated background elements. The frequent use of motion can make the interface feel visually busy and distract users from the overall content structure.

**Impact:**

- Increases visual complexity.
- Depending on implementation, excessive animations may also affect rendering performance.

**Recommendation:**

Reduce unnecessary animations and use motion selectively where it adds value to the user experience. Keep animations subtle and purposeful, optimize their implementation, and respect the `prefers-reduced-motion` accessibility preference.

### 2.7. Delayed Navigation to Detail Pages

**Priority:** High

**Issue:**

When clicking on cards in certain homepage sections, there is a noticeable delay before navigating to the corresponding detail page. This creates an inconsistent navigation experience across different sections.

**Impact:**

- Makes the interface feel less responsive.
- May cause users to click multiple times because they are unsure whether their interaction was registered.
- Interrupts the browsing experience.
- Can reduce user satisfaction when exploring marketplace content.

**Recommendation:**

Investigate the navigation behavior of cards across different sections to identify the source of the delay. Optimize the navigation flow and provide immediate visual feedback when a card is clicked.

## 4. Review Scope

This report presents an evaluation of the original Witchly website, highlighting identified UX/UI issues and providing practical recommendations to improve visual consistency, usability, navigation, and the overall user experience.

## 5. Conclusion

The review identified several opportunities to improve the Witchly marketplace experience, particularly in terms of visual hierarchy, homepage clarity, navigation responsiveness, and consistency across page layouts.

Addressing these areas could help create a more intuitive, visually balanced, and user-friendly marketplace experience.
