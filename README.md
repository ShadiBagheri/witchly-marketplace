# witchly-marketplace

A responsive marketplace application built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui.

## Getting Started

Install dependencies:

    pnpm install

Run the development server:

    pnpm dev

Open http://localhost:3000 in your browser.

You can start editing the page by modifying `src/app/page.tsx`.
